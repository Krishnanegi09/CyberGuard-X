# 10 — UI Direction: "Cinematic Security Command Center"

## Visual language
- **Palette:** deep charcoal and black surfaces, restrained cyan as the main accent, controlled red only for threats, subtle blue light for depth.
- **Text and layout:** clean type with a monospace face for IPs, ports and hashes; dense but uncluttered layout; subtle motion only.
- **Themes:** dark (default) and light, with every colour defined as a token in `src/theme/`.
- **Avoid:** gradient overload, random glow, generic admin templates, nested cards, and decorative charts with invented values.

## Truthfulness in the UI
- **Provenance badges** on every data item: `OBSERVED`, `DERIVED`, `PREDICTED` (with the model version on hover), `SIMULATED`.
- **Simulation mode** has a distinct look: tinted canvas, a persistent "SIMULATION — not live data" banner, and its own route prefix (`/simulate/...`).
- **Every data view needs three states besides data:** loading, empty ("No network assets discovered yet. Start a discovery scan in Observe."), and error (message, retry button, request ID).
- The packet and flow view is split into **Flagged** and **Not flagged**, never "Safe". Flagged rows link to the detection and its evidence.
- The sensor status chip shows `live`, `stale` or `offline` from the real heartbeat.
- The risk score has a tooltip that shows the formula and each component.

## Navigation (show only what is implemented)
Overview · Observe (Assets, Scans, Monitoring, Topology) · Understand (Findings, Vulnerabilities, Incidents) · Simulate (Digital Twin, Attack Paths, What-if) · Predict (Models, Predictions, Risk) · Defend (Recommendations, Actions, Emergency Stop) · Learn (Feedback, Datasets, Evaluations) · Reports · Settings (Org, Members, Scope, Sensors) · Audit Log.
Unbuilt sections are hidden behind a feature flag, not shown with fake content.

## Accessibility
WCAG AA contrast in both themes; full keyboard navigation; `prefers-reduced-motion` honoured; never rely on colour alone, so severity also has an icon and text.
